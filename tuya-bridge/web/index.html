Tuya Bridge

Tuya Wi-Fi devices inside your SONOFF iHost — controlled locally, no cloud.

1 Connect the iHost

2 Import your Tuya devices

Each device needs its local key. Get them once from your free Tuya IoT cloud project (after that, the cloud is never used for control).

From the Tuya cloud project
Or paste devices.json (from python -m tinytuya wizard)

3 Find them on the network and add to the iHost
