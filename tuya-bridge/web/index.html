Tuya Bridge

Tuya Wi-Fi devices inside your SONOFF iHost — controlled locally, no cloud.

1 Connect the iHost

2 Import your Tuya devices

Each device needs its local key. Get them once from your free Tuya IoT cloud project (after that, the cloud is never used for control).

From the Tuya cloud project
Or paste devices.json (from python -m tinytuya wizard)

3 Find them on the network and add to the iHost

Control runs from this bridge straight to each device (TCP 6668). Status is refreshed every few seconds. Service address:

IR codes

Teach the bridge your AC remote, one state at a time. Set the remote to the state first (e.g. Cool, 24°), then press Learn and press any button on the remote while pointing it at the IR transmitter — AC remotes send the whole state with every press. Commands without a learned code use the Tuya cloud (if set up).
